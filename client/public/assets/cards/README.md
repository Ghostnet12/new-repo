# FRACTURE Shadow Deck — 4K card assets

This directory is the production card-art source for the React client.

- `00.webp`–`21.webp`: Major Arcana
- `22.webp`–`35.webp`: Wands
- `36.webp`–`49.webp`: Cups
- `50.webp`–`63.webp`: Swords
- `64.webp`–`77.webp`: Pentacles

Each file is an individual 2731×4096 WebP master generated for this Shadow Deck. The website loads these files directly; the legacy sprite atlas is not used by the card renderer.
