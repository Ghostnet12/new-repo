# Individual Shadow Deck card assets

The production React client loads one file per card from this directory.

- `00.webp`–`21.webp`: Major Arcana
- `22.webp`–`35.webp`: Wands
- `36.webp`–`49.webp`: Cups
- `50.webp`–`63.webp`: Swords
- `64.webp`–`77.webp`: Pentacles

The 4K masters remain the canonical artwork source. These WebP files are exact visual derivatives optimized for browser delivery and replace the legacy runtime sprite atlas.
